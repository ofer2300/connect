נוצר עותק Git מבודד מסוג mirror, ללא פריסת קובצי המקור וללא הרצת קוד מתוכו. מקור העותק הושווה לשם המאגר. כל אובייקטי התוכן הנגישים נקראו בידי הסורק, והמסמכים ושינויי ההיסטוריה נבחנו. בדיקת git fsck --full הסתיימה בקוד 0 ללא ממצאים. נבדקה תקינות שמות הענפים המוצעים. ספירות המלאי הוצלבו עם צילום המצב.

לא הורצו כלים של Ara 3D, לא הותקנו תלויות ולא בוצעה בדיקת Revit/Rhino או חיבור BIM חי. סריקת הדפוסים המצומצמת לא מצאה מפתחות פרטיים או אסימוני GitHub בדפוסים שהוגדרו; אין בכך הוכחה שאין סודות. תוצאת התראות הסודות בשרת הייתה ריקה, אך חלק מממשקי האבטחה האחרים חסומים.

המשך מוצע

הערך המיידי הוא מניעת השקעת זמן בהתקנת מערכת שהמאגר אינו מספק. לשימוש כרעיון הנדסי, יש תחילה להשלים מפרט זהויות, דוגמת נתונים ותרחיש שחזור; לאחר מכן לאתר מימוש קיים או לתחום ניסוי קטן. אין בדוח אומדן חיסכון כספי או הוכחת התאמה לפרויקט אמיתי.

מילון קצר ונספחים

Commit — נקודת שמירה; Branch — קו עבודה; Tag — שם שמצמידים לגרסה; SHA — מזהה תוכן; PR — בקשת מיזוג וביקורת; Actions — משימות אוטומטיות של GitHub; Artifact — קובץ תוצר מהרצה; Release — פרסום גרסה להורדה; Hash — חתימה מחושבת של תוכן; Snapshot — צילום מצב. MD5 המוזכר בתכנון הוא סוג של חתימת תוכן; התאמתו לדרישות המערכת לא אומתה.
